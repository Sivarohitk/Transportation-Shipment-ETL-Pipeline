## Evidence boundaries

- The [local smoke result](results/local-smoke-60.json) used 60 synthetic shipments and 120 events with Windows `json_fallback`. It is a benchmark-harness check, not evidence of Parquet, S3, or million-row throughput.
- The [Databricks deployment record](databricks_deployment.md) documents an earlier development-workspace run. Later local correctness changes have not been redeployed and rerun there.
- EMR, Glue Spark, Glue Data Catalog, Redshift, S3 adapters, and CloudWatch have code and local tests, but no live AWS validation artifact. Do not describe them as production-operated systems.
